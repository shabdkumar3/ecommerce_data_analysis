# E-commerce Data Analysis and Sales Dashboard

## Project Overview
This project focuses on analyzing e-commerce sales data and presenting insights through an interactive Power BI dashboard.  
The objective is to extract meaningful business insights related to sales performance, product trends, and regional analysis.

---

## Objectives
- Analyze overall sales and revenue performance
- Identify top-selling products and categories
- Track sales trends over time
- Understand customer and regional performance
- Present insights using interactive dashboards


---

## Dashboard Features
- Total Sales and Revenue KPIs
- Monthly and Yearly Sales Trends
- Category-wise and Product-wise Analysis
- Region-wise Performance
- Interactive Filters and Slicers

---

## Tools and Technologies
- Power BI Desktop
- CSV Dataset
- Power Query for data cleaning
- DAX for calculated measures
- GitHub Releases for large file hosting

## How to Use
1. Download the dataset from the v1.0_data release
2. Download the Power BI dashboard from the v1.0_dashboard release
3. Open the .pbix file using Power BI Desktop
4. If prompted, connect the dashboard to the downloaded dataset
5. Refresh the data and explore insights using filters
